# Mis tarjetas — primera etapa

Prototipo móvil de la pantalla Inicio para registrar tarjetas y consultar deuda, límite total y disponible en ARS y USD.

## Incluye

- Diseño adaptable a celulares y escritorio, con las cinco opciones inferiores.
- Alta, edición y eliminación de tarjetas.
- Resumen de límites y deuda separado por moneda.
- Progreso visual del límite utilizado.
- Guardado local en el navegador del dispositivo.
- Preparación como PWA para instalación desde un sitio publicado con HTTPS.

## Alcance actual

Los datos quedan guardados solo en el navegador y dispositivo donde se cargan. Todavía no hay cuentas, sincronización entre dispositivos, ni registro de compras/cuotas. Las otras secciones aparecen como próximas etapas. No guardar número completo, vencimiento ni código de seguridad de la tarjeta.

Para compartir un enlace instalable, primero hay que publicar estos archivos en un hosting HTTPS. Eso se puede resolver cuando terminemos esta etapa y definamos cómo querés que cada persona guarde y sincronice sus datos.
